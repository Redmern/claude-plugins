# teach

Two skills for learning a topic with Claude Code:

- `/teach:teach`: learn over several sessions, with a mission, lessons, a
  glossary and a learning record in your workspace.
- `/teach:teachxl`: `teach` plus interactive HTML lessons with live in-page chat.

`skills/teach` comes from [mattpocock/skills](https://github.com/mattpocock/skills)
(MIT, see `skills/teach/LICENSE`). `skills/teachxl` builds on it and reads its
format files, so the two skills ship together.
